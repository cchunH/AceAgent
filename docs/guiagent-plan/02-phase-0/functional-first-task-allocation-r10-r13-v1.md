# 功能优先任务分配（R10-R13）v1

## 文档元信息

- 状态：`active`
- 版本：`v1.2`
- 更新时间：`2026-03-08`
- 关联主文档：`../01-global-analysis/guiagent-blueprint-fidelity-review-v1.md`

## 1. 目标与原则

1. 目标
- 在保证系统可运行前提下，优先补齐 GUIAgent 核心功能闭环。

2. 原则
- 先功能可用，再生产级稳态。
- 每项任务必须映射蓝图流程（A/B/C）。
- `群智联邦分发（流程 D）` 明确后置，不纳入 R10-R13。

## 2. 工作流分组

### Track A：在线执行与校验链（流程 A/B）

1. A1 执行状态机抽离
- 目标：将 `v2_executor` 中流程状态显式化。
- 输出：状态机图 + 单元测试。

2. A2 多级断言细化
- 目标：将拓扑断言、语义断言、骨架断言阈值可配置。
- 输出：策略参数与事件指标联动。

3. A3 自愈协议增强
- 目标：规范 L1/L2/L3 触发条件和重试上限。
- 输出：失败码映射表与回归用例。

4. A4 流程审查器接入
- 目标：运行后自动检查主流程链路完整性，避免“能跑但链路断裂”。
- 输出：`runtime_summary.flow_audit` 与回归测试。

### Track B：离线复盘与回灌（流程 C）

1. B1 复盘评分器
- 目标：对离线重建产物打分，低分不入库。
- 输出：`replay_quality_score` 指标。

2. B2 Delta 补丁策略
- 目标：仅更新受损锚点/骨架片段。
- 输出：补丁格式与回滚策略。

3. B3 回灌验证闭环
- 目标：验证“失败样本 -> 回灌 -> 再执行命中”的链路。
- 输出：最小闭环回归测试。

### Track C：检索层与向量库（流程 C/04 契约）

1. C1 `VectorIndexAdapter` 抽象
- 目标：统一向量检索接口，不绑定具体后端。
- 输出：接口 + 本地 mock 实现。

2. C2 离线向量召回实验
- 目标：意图对齐与蓝图候选召回 A/B 对照。
- 输出：recall/precision 报告。

3. C3 在线向量后端接入（后置）
- 目标：接入 Qdrant/Milvus/pgvector 之一。
- 输出：运行配置、降级策略、成本评估。

### Track D：状态/控制面增强（流程 A/B/C 支撑）

1. D1 回灌可观测面板字段
- 目标：在 metrics 与 timeline 中体现回灌效果。
- 输出：新增指标与 API 字段文档。

2. D2 长周期数据治理
- 目标：时间线归档、冷热分层、审计聚合。
- 输出：归档策略与查询性能基线。

3. D3 发布门禁
- 目标：将关键指标接入发布检查清单。
- 输出：自动化回归与阈值门槛。

## 3. 里程碑与顺序

1. M1（R10）：A1+A2+A3 完成。
2. M2（R11）：B1+B2+B3 完成。
3. M3（R12）：D1+D2+D3 完成。
4. M4（R13）：C1+C2；C3 视指标达标后启用。

## 3.1 本阶段非目标

1. 不做群智联邦分发（蓝图 06/11）。
2. 不做跨节点共识与全网热更新机制。

## 4. 角色分工建议

1. Algorithm Owner
- 负责 Track A/B 算法与阈值策略。

2. Runtime Owner
- 负责 Track D 控制面与数据治理。

3. Retrieval Owner
- 负责 Track C 向量召回与后端适配。

4. QA Owner
- 负责闭环回归、误命中样本集、门禁维护。

## 5. DoD（完成定义）

1. 每项任务具备代码、测试、文档三件套。
2. 每项任务可映射到蓝图流程 A/B/C/D。
3. 每项任务有对应指标和可观测事件。
4. 不破坏 `runtime_mode=legacy` 回退能力。
