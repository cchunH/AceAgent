# 主辅锚点选择与辅助锚点作用思考 v1

## 文档元信息

- 状态：`active`
- 版本：`v1.0`
- 更新时间：`2026-03-08`
- 目标：为下一阶段锚点策略优化提供统一思路基线

## 1. 主辅锚点的定义边界

1. 主锚点（Core Anchors）
- 直接决定“动作坐标系是否成立”。
- 与关键意图语义强绑定（如搜索框、确认按钮、主标题）。
- 稳定性要求最高，匹配失败时优先触发 L2/L3。

2. 辅锚点（Aux Anchors）
- 不直接决定动作执行，但用于提高定位稳健性与容错。
- 承担“旁证、校准、歧义消解、恢复引导”职责。
- 在主锚点不充分时可临时接管一部分判断。

## 2. 主辅锚点选择建议（可执行口径）

1. 主锚点选择优先级
- 语义唯一性：文本/图标在当前页面区分度高。
- 空间稳定性：跨帧位移方差低。
- 任务相关性：与 `intent_key` 目标区域强相关。
- 结构中心性：位于可交互链路关键节点（导航栏、输入区、提交区）。

2. 辅锚点选择优先级
- 与主锚点形成几何约束（横向/纵向/对角）可用于校准。
- 能覆盖主锚点易受遮挡区域之外的位置。
- 在不同设备比例下保持相对位置关系稳定。

3. 建议数量
- 每步建议：主锚点 `1-2` 个，辅锚点 `2-4` 个。
- 避免锚点过多导致噪声权重反客为主。

## 3. 辅助锚点的特殊作用（深挖）

1. 辅助定位与坐标校准
- 主锚点给绝对目标，辅锚点提供相对几何关系（尺度/偏移/旋转近似）。
- 可作为仿射估计中的辅助约束点，提高跨分辨率稳定性。

2. 遮挡与模态干扰下的替代证据
- 主锚点被弹窗遮挡时，辅锚点可维持“仍在目标页面”判断，避免误回退。
- 若辅锚点整体偏离，优先触发页面偏移告警而非盲点操作。

3. 歧义消解
- 当多个候选主锚点文本相似时，用辅锚点的上下文关系判定正确目标。
- 例如“搜索”文本多处出现时，辅锚点“顶部导航/输入区边界”可消歧。

4. 动态噪声过滤
- 辅锚点可以作为噪声探针：高波动辅锚点不参与执行坐标估计，但可更新动态槽位。
- 与 `dynamic_slots` 联动后，可降低把临时浮层当静态骨架的概率。

5. 恢复策略引导
- L1/L2 恢复中，优先尝试恢复辅锚点一致性；若仍失败再升级到主锚点失配路径。

## 4. 建议的运行时策略（下一步可实现）

1. 置信度分层
- `core_confidence`：主锚点加权匹配得分。
- `aux_confidence`：辅锚点一致性得分。
- `geometry_confidence`：主辅几何约束一致性得分。

2. 判定逻辑（建议）
- `core_confidence` 低：直接进入结构失败路径。
- `core_confidence` 中等且 `aux_confidence` 高：允许一次微扰重试。
- `core_confidence` 高但 `geometry_confidence` 低：优先做坐标校准再执行。

3. 事件可观测建议
- 新增字段：`core_anchor_count/aux_anchor_count/core_confidence/aux_confidence/geometry_confidence`。
- 对误触场景保留主辅锚点命中明细，便于离线复盘。

## 5. 当前代码映射与差距

1. 已有基础
- 锚点具备 `role=CORE|AUXILIARY`。
- 拓扑匹配已实现角色加权（`CORE` 优先）。
- 状态骨架已记录 `dynamic_slots`。

2. 仍需补齐
- 主辅锚点分路评分（目前仍以统一匹配分数为主）。
- 主辅锚点对仿射执行链的显式约束接口。
- 辅锚点失配到恢复策略的细粒度映射。

## 6. 结论

辅助锚点不应只是“凑数量”的次要点，而应作为：
1. 主锚点的几何校准器；
2. 动态噪声的识别器；
3. 失败恢复的分流器。

后续建议沿“主锚点决定动作，辅锚点决定是否可信地执行动作”的原则继续推进。
