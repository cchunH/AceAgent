**设计视角**：阐述 AceAgent-Swarm 在复杂真实环境中的韧性保障。引入“导航偏离”视角，将 UI 干扰视为路径上的动态障碍物。通过多维雷达感知，系统能够自动识别异常，并在“微扰自愈”、“优雅降级”与“大脑接管”之间进行无缝切换。

---

## 1. 核心定义与设计思辨：从“报错”到“避障”

在传统的自动化设计中，预料之外的 UI（如弹窗）通常导致脚本报错退出。AceAgent-Swarm 引入**导航自愈逻辑**：
*   **非线性路径 (Non-linear Path)**：系统认为从 A 到 B 的路径不是一成不变的。弹窗、权限申请、广告拦截被定义为“路径上的临时障碍物”。
*   **避障机制 (Obstacle Avoidance)**：小脑利用雷达感知（文档 02）发现障碍，尝试自动绕行；若绕行失败，则交由大脑（System 2）进行逻辑层面的路径重规划。

---

## 2. 障碍物识别：多维雷达探测 (Obstacle Detection)

### 2.1 Z-轴视觉冲突：模态弹窗识别
当系统在安全区（Top/Bottom 15%）探测指纹时，若发现指纹匹配度骤降，但屏幕中心出现高对比度矩形区域：
*   **识别逻辑**：判定为 **Z-轴遮挡（Modals）**。系统检查背景是否变暗（Dimness），判断是否为系统级或应用级弹窗。
*   **策略**：小脑挂起当前任务，尝试在弹窗范围内寻找“关闭/我知道了”等通用语义锚点执行避障。

### 2.2 状态漂移：加载中与网络异常
*   **感知特征**：屏幕像素指纹持续剧烈波动（Jitter），但无有效语义锚点生成。
*   **自愈协议**：进入**自适应等待（Adaptive Wait）**。小脑监听像素波动率，仅在波动率 $< 1\%$ 的“稳态”下重新尝试指纹匹配。

---

## 3. 自愈协议分级：优雅降级 (Graceful Degradation)

当小脑的“避障雷达”发现偏离预期时，触发分级自愈逻辑：

### L1 级：微扰自愈 (Micro-Jitter) —— *针对执行失效*
*   **场景**：点击后页面无反应，后置校验失败。
*   **动作**：在原坐标 $\pm 5px$ 范围内进行微小的随机偏移重试，解决由于 UI 层级透明遮挡导致的“假点击”。

### L2 级：逻辑降级 (Logic Degradation) —— *针对环境偏离*
*   **场景**：页面主锚点匹配成功，但动作目标的“语义断言”失败。
*   **动作**：暂停快路径。小脑尝试执行“刷新”或“退回重进”操作，试图将 App 状态强制重置回蓝图可识别的基准点。

### L3 级：大脑接管 (Brain Handover) —— *针对未知障碍*
*   **场景**：L1/L2 尝试均告失败，或遇到了完全陌生的 UI 结构。
*   **动作**：小脑立即挂起，将全屏快照及冲突断言（Conflict Assertions）打包上传给 **System 2 (大脑)**。
*   **结果**：大脑进行全量推理，识别障碍物本质（如：是一个从未见过的新版升级提示），下达单步避障指令，并触发离线进化的“认知回灌”。

## 4. 隐私与性能的边界防护

### 4.1 隐私脱敏：共享指纹的安全性
在 Swarm Hub 进行群体经验共享前，必须经过**“语义脱敏门槛”**：
*   **机制**：本地 Agent 强制擦除所有非结构化文本中的 PII（个人敏感信息）。
*   **原则**：共享的是“在这个按钮旁边点那个按钮”的几何拓扑，而非“这个按钮上写的具体名字”。

### 4.2 性能红线：发热与功耗管理
端侧 OCR 与雷达感知是高功耗操作。
*   **降频机制**：当手机电池温度 $> 42^{\circ}C$ 或电量 $< 10\%$ 时，系统自动降低感知频率，将“每步校验”切换为“关键帧校验”。

## 5. 常见问题深度解答 (FAQ)

**Q: 为什么不使用 Android 的资源 ID (Resource-ID) 来处理所有边界？**
**A:** 资源 ID 是极具欺骗性的。现代 App（如 Flutter/React Native 开发）的 ID 往往是动态生成的随机字符串，或者在不同版本间频繁更替。**星群拓扑 + 语义断言**的鲁棒性远高于依赖硬编码路径，它更接近人类视觉识别的本质。

**Q: 系统如何区分“加载中”和“App 卡死”？**
**A:** 通过**像素波动率监测**。加载中通常伴随着局部动画，像素哈希处于波动态；而卡死则是像素哈希绝对静止且指纹匹配持续失败。系统对二者有不同的超时惩罚逻辑。

---

## 6. 总结 (Summary)

AceAgent-Swarm 的边界工程不再是零散的补丁，而是一套基于**感知-决策-反馈**的完整导航体系。

通过将异常情况转化为“可感知、可避障”的动态状态，AceAgent 实现了在复杂移动端生态中的高可用性。**System 1 负责通过本能避开小坑，System 2 负责在迷路时重画地图。** 这种分层自愈能力是 Agent 能够无人值守运行的最终屏障。
