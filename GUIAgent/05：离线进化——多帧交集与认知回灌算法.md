**设计视角**：阐述系统如何将 System 2（大脑）的昂贵推理过程“编译”并“回灌”为 System 1（小脑）的肌肉记忆。本模块是 AceAgent-Swarm 实现从“新手”到“专家”跨越的核心引擎。

---

## 1. 核心定义与演进逻辑 (Core Definition & Evolution)

### 1.1 从“统计去噪”到“成功学习”
早期的 Agent 进化仅依赖于对 UI 变化的统计学去噪。在 AceAgent-Swarm 架构中，离线进化层（Evolution Layer）承担了更深层的使命：**认知回灌（Cognitive Back-propagation）**。
*   **不仅仅是去噪**：它不仅要通过“多帧交集”识别出背景，更要复盘 System 2 的每一个成功决策。
*   **编译过程**：将 System 2 在“开荒模式”下的高能耗逻辑（如：分析弹窗、处理异常、寻找改版控件）压缩为 System 1 可直接执行的“动作-状态指纹”映射表。

---

## 2. 数据来源：双模态经验输入

离线进化层不再只盯着历史轨迹，而是建立了两路数据优先级：

1.  **路径 A：多帧统计轨迹（Statistical Traces）**
    *   **来源**：System 1 在快路径中成功执行的海量日常操作。
    *   **价值**：用于高精度地提取“幽灵骨架”，识别 UI 的静态基准和动态噪音区。
2.  **路径 B：大脑成功轨迹（S2 Success Traces - 黄金经验）**
    *   **来源**：当 System 1 失效后，System 2 介入并最终解决问题的“绕路”记录。
    *   **价值**：这是最高优先级的训练集，包含了 UI 改版或异常处理的**正确答案**。

---

## 3. 核心算法流程：幽灵骨架提取与认知回灌

### 3.1 幽灵骨架提取 (Ghost Skeleton Extraction)
系统通过对同聚类（Clustered）页面的多帧采样进行“长曝光”处理：
*   **节点级交集**：在像素与 UI 树层面寻找 100% 恒定的节点。
*   **动态槽位标记 (Slotting)**：将频繁变化的区域（如视频流、广告位）标记为“逻辑黑洞”，强制 System 1 在执行前感知时忽略这些区域的视觉差异。
*   **结果**：产出一个剔除了干扰、仅保留“主辅星群锚点”的纯净导航底图。

### 3.2 认知回灌算法 (Cognitive Back-propagation)
当检测到一段由 System 2 驱动的成功轨迹时，系统启动回灌流程：
1.  **意图重映射**：System 2 虽然是通过复杂的 VLM 视觉推理点中的按钮，但回灌算法会将其映射回**意图库中的标准化 Key**。
2.  **关键帧捕捉**：记录动作发生前后的指纹差异（$\Delta Fingerprint$）。
3.  **蓝图热修复 (Hot-fix)**：
    *   如果这是一个 UI 更新（按钮移位），系统会生成一个新的 **“指纹-坐标”补丁**，覆盖旧蓝图。
    *   如果这是一个逻辑分支（如：弹窗阻碍），系统会在蓝图中增加一个 **“前置检查（Pre-condition）”** 状态位。

## 4. 进化产物：高精蓝图 (Skill Blueprint v2.0)

进化层输出的不再是简单的脚本，而是包含“语义、几何、逻辑”三位一体的 **技能胶囊**：

| 组件 | 内容 | 作用 |
| :--- | :--- | :--- |
| **拓扑指纹** | 经去噪后的主辅锚点星群 $(Core + Aux)$ | 确保 System 1 能够瞬间识别页面并建立坐标系 |
| **意图断言** | 目标控件的局部语义特征 (OCR/Icon Hash) | 供 System 1 执行前的 Sense Check 校验，防止点错 |
| **动作参数** | 基于仿射变换的相对重心坐标矩阵 | 确保在任意分辨率、拉伸比例下的点击精准度 |
| **后置预期** | 执行成功后页面应呈现的指纹特征 | 用于动作后的闭环反馈检查 |

---

## 5. 差分修正与自愈能力 (Delta Correction)

系统遵循 **“极小化修改”** 原则。如果一次改版仅影响了局部，系统只更新受损的锚点三角形，而非重写整个流程。
*   **权重调节**：如果某个锚点在最近的 100 次匹配中稳定性下降（如：位置微移），系统会自动降低其在“法定人数匹配（Quorum Match）”中的权重。
*   **自动泛化**：当系统发现多台设备都在“瑞幸”和“美团”的结算页表现出相似的 UI 结构，它会尝试提取一个跨 App 的 **“通用意图模板”**。

---

## 6. 总结 (Summary)

AceAgent-Swarm 的离线进化层是整个系统从“自动化脚本”转向“智能化体”的质变点。它通过 **“多帧交集”** 解决了 UI 的复杂性，通过 **“认知回灌”** 解决了逻辑的变动性。

**它的核心价值在于：将大脑（System 2）探索出的每一个“新知识”，都固化为小脑（System 1）不需要思考就能执行的“本能”。** 这种进化的闭环，使得 Agent 在面对频繁更新的 App 生态时，依然能保持极高的生存力和响应效率。
